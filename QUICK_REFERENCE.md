## 🔥 firebase integration

### required files:
- `android/app/google-services.json` (dari firebase console)
- `ios/Runner/GoogleService-Info.plist` (dari firebase console)
- `lib/firebase_options.dart` (auto-generated by flutterfire)

### setup:
1. buat project di https://console.firebase.google.com
2. tambah aplikasi android & ios
3. download konfigurasi files
4. letakkan di path yang benar
5. jalankan `flutterfire configure` (opsional, untuk auto-generate)

## 🐛 troubleshooting quick fixes

### flutter build gagal
```zsh
# clear build
flutter clean
flutter pub get

# rebuild
flutter run
```

### firebase init error
```zsh
# check firebase_options.dart exists
ls lib/firebase_options.dart

# check google-services.json
ls android/app/google-services.json

# if missing, run:
flutterfire configure
```

### null pointer exception
```
- check ? null coalescing operator
- check ?? default value
- check if (value != null) before use
```

### widget not showing
```
- check if parent has size constraints
- check if data loading (loading state?)
- check flutter inspector (devtools)
```

### dependency conflict
```zsh
# update all
flutter pub upgrade

# atau spesifik
flutter pub upgrade package_name
```
