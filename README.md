> **Modernizing Queue Culture.** Sebuah ekosistem digital terintegrasi (Mobile & Web) untuk manajemen barbershop modern dengan optimasi antrean berbasis AI.

---

## 🌟 Vision
GEGES Smart Barber mentransformasi pengalaman tradisional mengantre di barbershop menjadi sistem digital yang efisien, transparan, dan cerdas. Menggabungkan kemudahan pemesanan mobile dengan dashboard manajemen operasional yang komprehensif.

---

## 🛠️ Integrated Modules
1. **Customer App (Flutter):** Booking online, tracking antrean real-time, dan integrasi pembayaran.
2. **Admin Dashboard (React/Web):** Manajemen tenant (barbershop), audit laporan keuangan, dan verifikasi pembayaran.
3. **AI Core:**
   - **NLP Chatbot:** Asisten virtual untuk tanya-jawab layanan.
   - **Computer Vision:** Analisis citra untuk fitur pendukung (misal: rekomendasi gaya rambut).
4. **Queue Engine:** Algoritma pembagian tugas barberman yang adil berdasarkan beban kerja bulanan.

---

## 🚀 Technical Highlights
- **Real-time Engine:** Sinkronisasi status antrean instan di seluruh perangkat menggunakan Firestore Streams.
- **Enterprise Lifecycle:** Manajemen tenant lengkap dari pendaftaran, suspend, hingga penghapusan permanen (Cascading Delete).
- **Professional Testing:** Mencapai **188+ Unit & Widget Tests (100% Pass Rate)** untuk stabilitas platform.
- **Fair Assignment Logic:** Sistem otomatisasi penugasan barberman untuk menjaga keseimbangan beban kerja karyawan.
