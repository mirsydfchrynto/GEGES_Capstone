# GEGES Smart Barber Ecosystem

Ekosistem digital modern berbasis AI untuk transformasi budaya antrean barbershop. Terdiri dari aplikasi mobile pelanggan dan dashboard admin web.

## Fitur Utama

* **Real-time Queueing:** Sistem antrean langsung yang terintegrasi dengan Firestore untuk update instan.
* **AI Integration:** Implementasi NLP Chatbot untuk bantuan pelanggan dan Computer Vision untuk analisis citra.
* **Comprehensive Payment:** Integrasi alur verifikasi pembayaran manual dan otomatis.
* **Multi-platform:** Berjalan di Android, iOS, dan Web dari satu codebase yang efisien.

## Tech Stack

* **Mobile:** Flutter (Dart)
* **Backend:** Firebase (Auth, Firestore, Cloud Messaging)
* **Web Admin:** TypeScript, React
* **Testing:** 180+ Unit & Widget Tests (100% Coverage).

## Highlight Teknis

Proyek ini membuktikan kemampuan saya dalam mengelola Full Software Development Life Cycle (SDLC), mulai dari perancangan arsitektur, testing otomatis (CI/CD), hingga deployment pada platform Android dan Web.
