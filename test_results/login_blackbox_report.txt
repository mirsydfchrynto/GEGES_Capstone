Test Level: Functional Testing
Testing Type: Black-Box Testing
Technique Used: Equivalence Partitioning (EP)
Prepared By: Marsha

OBJECTIVE
Pengujian ini memastikan fitur Login bekerja sesuai kebutuhan fungsional: memverifikasi validasi input, perilaku saat kredensial benar/salah, dan navigasi berdasarkan role pengguna.

SCOPE
Fitur yang diuji:
- Field `Email`
- Field `Password`
- Tombol `Masuk`

Output yang diharapkan:
- Navigasi ke halaman utama (Home / AdminDashboard) jika login berhasil
- Pesan error atau validasi jika input tidak sesuai atau terjadi kegagalan autentikasi

9  | Kombinasi   | Salah satu tidak valid | irsyad@gmail.com / 1234abcd | Pesan error sesuai kondisi

IMPLEMENTATION NOTES (terkait `AuthService.signIn()`)
- Jika autentikasi Firebase gagal, `AuthService.signIn()` menangkap `FirebaseAuthException` dan mengembalikan:
  `{'success': false, 'message': e.message ?? 'Login gagal'}`
  Artinya teks pesan yang ditampilkan di UI berasal dari `FirebaseAuthException.message` kecuali kita menambahkan mapping pesan di service.
- Jika autentikasi berhasil tetapi dokumen Firestore pengguna tidak ditemukan, method mengembalikan `{'success': false, 'message': 'Data pengguna tidak ditemukan.'}`.
- Jika autentikasi & Firestore berhasil, method mengembalikan `{'success': true, 'role': role}`.

ANALYSIS & RECOMMENDATIONS
1) Konsistensi Pesan Error
   - Saat ini pesan error diteruskan dari `FirebaseAuthException.message`. Untuk black-box testing yang mengandalkan teks persis, sebaiknya tambahkan mapping `code → localized message` di `AuthService`.
   - Alternatif yang lebih longgar: uji berdasarkan behavior (success/failure) dan bukan teks exact.

2) Validasi UI vs Server
   - Validasi format email dan required fields adalah tanggung jawab UI (sebelum network call). Gunakan widget tests untuk memastikan pesan validasi muncul tanpa memanggil service.

3) Tambahan Test Cases yang Direkomendasikan
   - Network error / timeout → pastikan UI menampilkan pesan jaringan yang ramah.
   - Too-many-requests / rate limit → pastikan handling dan pesan user-friendly.

TEST EXECUTION NOTES
